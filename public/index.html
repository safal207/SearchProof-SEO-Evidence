SearchProof converts a page audit or site crawl into a chain you can verify: URL → finding → evidence → change → metric → observed result.

v0.3.1 combines bounded same-origin crawl evidence with a search experiment lifecycle. Use npm run audit -- URL for a detailed single-page report.

SITE CRAWL · v0.2

From page checklist to search graph.

01

Internal-link graph

Bounded same-origin BFS records exact page-to-page edges instead of only counting links on one document.

02

Duplicate clusters

Titles, H1s and descriptions are grouped across crawled pages so intent overlap becomes reviewable evidence.

03

Sitemap vs crawl

Sitemap-only URLs are flagged as orphan-like candidates, while crawled pages missing from the sitemap are kept separate.

04

Observed failures only

A link is called broken only when SearchProof actually fetched the internal target and observed a failing status.

PRODUCT RULES

Built like a QA system for search.

01

Observed ≠ inferred

HTML evidence, crawler responses and measured search data stay separate from recommendations.

02

Scores are heuristics

SearchProof never presents its prioritization score as a score from Yandex, Google or an AI provider.

03

Every fix gets a metric

A recommendation without a verification path is incomplete.

04

AI Search without magic

AEO/GEO checks focus on entities and answer structures, not guaranteed citations.
