Evidence is the product.

SearchProof converts a page audit into a chain you can verify: URL → finding → evidence → change → metric → observed result.

MVP audits URLs from the Node CLI. The browser dashboard visualizes evidence reports without pretending that client-side CORS can crawl the web.

PRODUCT RULES

Built like a QA system for search.

01

Observed ≠ inferred

HTML evidence, crawler responses and measured search data stay separate from recommendations.

02

Scores are heuristics

SearchProof never presents its prioritization score as a score from Yandex, Google or an AI provider.

03

Every fix gets a metric

A recommendation without a verification path is incomplete.

04

AI Search without magic

AEO/GEO checks focus on entities and answer structures, not guaranteed citations.
